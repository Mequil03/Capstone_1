# Capstone 1: Connecticut Sales Analysis
## Project Summary
This project shows the analysis of Connecticut's sales performance for our company, EmporiUm. To complete this project, I used SQL for queries, Excel for visuals, and created a video explaining my thought process. The goal of this project is to explore trends of sales, compare performance with territories vs regions, and identifying opportunities to improve sales performance in Connecticut.
## Tools
- MySQL Workbench
- SQL
- Microsoft Excel
- Git/Github
## Scenario Overview
I started a job as a data analyst at a growing business called EmporiUm. A sales manager tasks me with the territory Connecticut and creating an analysis of its sales performance. They want specific questions answered such as total revenue for Connecticut, compare it vs the regional revenue, and breakdown its sales by dates. 
## Key Points
- Total Connecticut Revenue: $2,392,222.44
- East Region Revenue: $6,723,039.53
- Connecticut Contribution: 35% of Regional Revenue
- High-selling Connecticut Store: New London (2272 sales, $331,116.76)
- Low-selling Connecticut Store: Old Saybrook (2191 sales, $277,310.18)
- Best Product Average Sold: Technology & Accessories ($649.77)
